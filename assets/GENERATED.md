# Generated assets

`icons.json` (the Lucide icon set the desktop client draws, one entry per icon: absolute SVG path data and whether it is filled) and `cat-rigs/<look>-<mood>.json` (every cat rig the client can draw: 72 looks x 8 moods) were generated by the Bend-era `native/gpui/gen/icons.bend` and `cat_rigs.bend` from `src/core/icons.bend` and `src/core/cat.bend`. Those sources were removed with Bend (5b7ff2832f), and the outputs never changed afterwards (the same sha256 in every dev build since), so they are kept here as files. Change them only with a new generator; `release.yml` refuses an archive without them, and the client logs `icon X not in icons.json` when one is missing.
