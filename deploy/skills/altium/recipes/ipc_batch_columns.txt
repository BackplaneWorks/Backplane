# IPC Compliant Footprints Batch generator (pcblib_ipc_batch.pas): the CSV each package type takes, from Altium's templates
# (<ProgramData>\Altium\Altium Designer {...}\Extensions\IPC Footprint Generator\Templates\*.xls, their Data sheet).
# A CSV is: line 1 = the package line below as is; line 2 = its column names; then one line per footprint. Dimensions in mm,
# min and max from the datasheet. No commas inside a field (a comma splits it). Leave optional columns empty.
# Worked example (SOIC, TI D package, 8 pins), tested:
#   SOIC127P600X175-8N,SOIC-8 (TI D) IPC nominal,5.8,6.2,0.31,0.51,0.4,1.27,3.8,4.0,4.8,5.0,1.35,1.75,0.1,0.25,,,8,1.27,,,,,,,,,N,,,,,,,,,,,,,,,,,,
# SOIC columns: H lead span (tip to tip), B lead width, L lead length, E body width, D body length, A height, A1 standoff, A2 body
# height, c lead thickness, PinCount (with absent pins), Pitch, AbsentPins/PinOrder (lists, need quotes: avoid), D2/E2 thermal pad
# (blank = none), DensityLevel L/N/M (least/nominal/most copper), JT/JH/JS fillet minimums; the footprint columns after
# DrawingNote (Z C G X Y pad geometry, A B assembly, V1 V2 courtyard, R1 R2 silk) override the computed values (leave blank).
# Other packages use the same letters for the same things (JEDEC drawing letters); blank FootprintName = IPC-7351 name.
