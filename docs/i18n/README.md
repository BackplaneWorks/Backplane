Catalogs are UTF-8 `i18n/<tag>.msg` files. English owns the key list.
Add a stable semantic key, translate it, then run:

    python3 scripts/i18n-gen.py
    python3 scripts/i18n-gen.py --self-test
    python3 scripts/i18n-gen.py --check

Commit catalogs and generated src/core/msgs.bend together. check.sh runs the
catalog gate. --check rejects missing/extra keys, placeholder mismatches and
stale output. Normal generation supports missing translations with an English
fallback; release checks require every translation. Fallback grammar uses English
plural rules too. test/fixtures/i18n_fallback.bend tests this independently of
production translations and is generated by the same command.

Each entry is `key = message`. Blank lines and # comments are ignored.
Leading/trailing whitespace is trimmed; use \s for significant spaces,
\n for a newline, and \\ for a backslash. Unknown escapes fail.
Keys contain lowercase letters, digits and dots; each segment starts with a
letter and cannot be a Bend keyword. Rewording preserves a key's meaning.

Messages support {name}, {name, number}, plural and select choices:
`{n, plural, =0 {None} one {# item} other {# items}}`.
Both choices require other; nesting works. # formats the nearest enclosing
plural number; outside plurals it is literal. Apostrophes quote before {}#|;
'' is an apostrophe; don't remains literal.
Every locale uses the same argument names. number/plural make an argument Nat;
select makes it String; plain placeholders inherit the cross-locale kind.
Combining Nat and select for one argument is an error.

Call T.<key>(locale, args...) with arguments in English first-appearance order.
T.keys lists sorted keys; T.missing lists fallbacks; T.plain looks up only
argument-free keys through a balanced String.cmp tree. Runtime ICU parsing and
catalog IO are absent. I18n.* supplies locale, number, date and time formatters.
Plural categories have a P prefix because Base already owns Zero.
Byte units use 1024 and truncate tenths below 10, integers from 10.
I18n.day's offset is eastward seconds; convert signed TzOff wall time at callers.
Run all Bend checks/builds through work_run lock bend and the project caps.
