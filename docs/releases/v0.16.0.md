# Backplane 0.16.0

0.16.0 puts KiCad inside Backplane. Press **Edit** on a board or schematic and KiCad's editor opens in the pane, where the viewer was, with your agents' edits showing live while you work. It also brings a quicker way for agents to edit KiCad, usage per account, streamer mode, an MCP servers page and a reworked first run. If you run 0.15.3 or an earlier 0.15, it offers this update; your threads and settings carry over as they are.

## KiCad inside Backplane

- **Edit opens KiCad in the pane.** The board or schematic you're looking at opens in Backplane KiCad's own editor inside the window, with no separate KiCad window to find. **Open in KiCad** does the same. **Full screen** gives the editor the whole window.
- **It's quick to switch.** KiCad starts in the background once a viewer is open, so the first Edit usually shows the editor straight away, with no blank frame in between. Switching between Board, Schematic and the viewers keeps KiCad where it was. KiCad closes after five minutes unused and when Backplane closes.
- **The keyboard goes where you expect.** KiCad's hotkeys work as soon as you press Edit, with no extra click. Backplane's own shortcuts still reach Backplane. On Windows this took a lot of work, and clicking into and out of the pane should now feel normal.
- **Agents and you edit the same board.** An agent's change appears in the open editor as it's made, and you can undo it from KiCad's Agents panel. When you're editing something an agent wants to change, the agent asks you first.
- **When KiCad asks something, you see it.** While KiCad has a dialog open, the pane's strip shows "KiCad is asking: …". KiCad's own notices go to the pane and to the agent instead of an extra window, on a runtime that supports this.
- **New panels beside the editor:** a live **BOM** with stock, price and lifecycle graphs, read from the open schematic (unsaved changes included); a **Checks** panel with DRC, ERC and the review findings in one list (click one to go to it in KiCad); a **Fab** panel with the fab's limits and Backplane's recommended values.
- **Routing plans.** On Backplane KiCad, agents can propose a routing plan (corridors per layer, plane regions) before laying copper. You approve it in KiCad, and the Plan panel and the PCB viewer both show it.
- **Comment to Backplane.** Select something in KiCad and press Ctrl+; (or use the right-click menu) to send it to a thread with your comment.
- **Backplane's KiCad library and KiCad's standard libraries ship with every Backplane KiCad runtime.** They're registered on a fresh install, and an update adds them to your existing library tables. A library you removed stays removed. Settings → CAD shows which library version is installed.
- **KiCad updates itself.** When a newer Backplane KiCad is pinned, Settings offers it with the reason. A download that's cut off picks up where it stopped.
- The Boards menu in the viewer bar moves KiCad to another board of the project. Clicking a part in the 3D view selects it on the board and in the schematic, and a probe lights the trace or part itself.
- Backplane never saves a file KiCad didn't change. Opening a board and saving without edits leaves every file byte-for-byte the same.

## `kicad_edit`: fewer steps for agents

Agents now make a KiCad edit with one tool, `kicad_edit`. It names parts by reference, works in millimetres, and in one call takes the document's lock, makes the change, saves and reports what DRC or ERC says the change added. It can also do the geometry itself: route a net at its net class's width and clearance, place a part next to a pin, or swap a footprint and keep its nets.

We measured eight typical edits on a demo project (move and rotate parts, set schematic fields, a net class, place symbols, a track and a via, a zone, custom rules, fix a DRC finding), each checked against a reference edit. With Claude Fable 5.2, compared with the raw `kicad_ipc` commands agents used before, the eight edits took about 17 tool calls instead of 195, and about a tenth of the context tokens. Every finished run passed, before and after. Against an agent editing the KiCad files directly (Claude Opus 5.5), `kicad_edit` used about a third fewer context tokens overall and got all 24 runs right where direct editing got 21. Direct editing is still as cheap or cheaper for small text-only edits such as a net class or a rule. These are medians from a small number of runs on one demo project, so treat them as a rough guide. The details are in [docs/kicad-ipc-bench.md](../kicad-ipc-bench.md).

## Pictures

- **Copy image** in a picture's right-click menu now puts the picture on the clipboard (it copied nothing before). **Save image as…** is there too, and the full view zooms and pans.
- **iPhone:** pictures in a reply show inline. Long-press one to **Save to Photos** or **Share image**, and pinch to zoom in the full view.

## Usage and accounts

- **Usage per account on the desktop and both phones.** Each account shows once, by email, with a bar for each of its limit windows. The CLI's own login says whose it is, and the same account added twice counts as one.
- **iPhone Settings** is reorganized into groups (Accounts & Usage, Hubs, Agents, Machines & devices, Notifications, Appearance, Updates, Improvements), with usage on the first page.
- When an account runs out, a turn moves to another account of the same provider that has usage left before trying another provider.

## Providers

- Usage is now counted for Pi, Grok, OpenCode and Muse.
- Grok and a resumed Muse session run the model you picked, not their default.
- A provider that isn't installed on this machine moves the request on, as a usage limit does. It no longer says the account "ran out".
- Antigravity runs your own `agy` CLI (1.4 or later) when Backplane's pinned one isn't installed.
- Paths with backslashes work on Windows.
- A turn cut off by a passing network or server error (a dropped connection, 502/503/504, overloaded) picks up again in the same thread.

## Streamer mode

Turn on **streamer mode** (Settings, Streaming) while you share your screen or record, or let it turn on by itself while the screen is shared. Backplane hides emails, home folder paths, machine names, addresses, account labels, pairing codes, machine invites and keys wherever they're drawn.

## Getting started

- **Setup is a short list of steps:** Welcome, Agents, Design tools, your uberbot's name, Where your uberbot lives, First project. Press ? or F1 for a sheet of keys.
- **Connect** signs an agent in directly, with no name to type, or reuses a login that's already there.
- "Where your uberbot lives" explains what the uberbot is and what a Boat is, with a link to learn more.
- **Name your uberbot** and pick its colour. Its cat changes as you type, and it arrives in the sidebar when you save. The cats are on the phones too.

## Also new

- **Settings → MCP servers** on the desktop and both phones: add a server by pasting its command or config, import the ones your other tools already use, or pick from a gallery. Your agents get the list.
- **Swarms:** threads that work as peers on a shared message board, shown live in the sidebar.
- **Text size** is a slider (80% to 160%).
- **Sidebar:** pin up to two threads under a project. Archived projects move to an Archived section, and chats with no project have their own section.
- A turn that runs out of memory or context ends on a calm card that says so in plain words.
- On macOS, a trackpad pinch zooms the viewers, and Quit and ⌘Q work.
- Bots remember long conversations (infinite context) by default.

## Security

Fixes from a security review:

- The hub's picture endpoint sends a strict Content-Security-Policy and no referrer.
- Pairing attempts are limited per client address, with a limit for the whole hub behind it.
- Streamer mode also hides machine invites and long hex secrets.
- The order server must be HTTPS (plain HTTP only to this machine), with no credentials in its address. Requests to it don't follow redirects, and the approval says where the request goes.
- Part-price lookups for a quote have a fair budget per quote and per install. A large board still gets priced, and a quote that can't be fully priced can't be paid.

## Installing

- **Linux and macOS:** `curl -fsSL https://github.com/BackplaneWorks/Backplane/releases/download/v0.16.0/install.sh | sh`, or press **Update** in the app.
- **Windows:** extract the zip and open `backplane-gpui.exe`, or press **Update** in the app. Windows may say "Windows protected your PC": choose **More info**, then **Run anyway** (the exe isn't signed yet).
- **Android:** install `backplane-v0.16.0-android.apk`. It installs over 0.15.
- **iPhone:** through TestFlight.

Backplane KiCad is installed or updated from **Settings → CAD** or setup's Design tools step.

## Known issues

- **Windows:** the programs aren't code-signed yet, so SmartScreen warns on first start. Managed PCs may not allow running them.
- **Macs older than macOS 15** don't get a managed Backplane KiCad. Settings says why.
- **A computer with no OpenGL 2.1 graphics** (some virtual machines and remote sessions) can show KiCad's "falling back to software rendering" message. Press OK and the pane works.
- **Japanese on Linux** needs a CJK font installed (for example Noto Sans CJK).
- The desktop Settings window isn't regrouped yet the way iPhone's is.
