# Backplane 0.16.4

## Mouse and trackpad

- **The viewers use KiCad's mouse controls.** The wheel zooms at the pointer, Ctrl + wheel and Shift + wheel pan, middle and right drag pan, the left button selects, and in 3D the left drag rotates. Settings → Mouse and trackpad has the **Legacy** preset, which is exactly how the viewers behaved before, and lets you set every input yourself, plus a zoom direction. Trackpad two-finger scroll and pinch work as before. The mapping and its source are in `docs/MOUSE-CONTROLS.md`.

## Bots: infinite context (beta)

- **Off by default.** Turn it on in Settings → Agents, **Bots: infinite context (beta)**. Each bot turn then starts fresh with the whole conversation as a tree of one-line summaries that the bot can zoom into, and a cheaper model writes them in the background. A bot's Settings tab can turn it off for that bot. (The 0.16.0 notes said it was on by default. It wasn't, and 0.16.0 didn't include it at all.)
- **You can see how far the memory is written.** A bot's Settings tab shows a bar of lines written out of the total, whether it's caught up or how many messages behind it is, and the view's size against its 128 KB limit. When a compactor call fails, it says the memory is held and when it will try again. In the thread, the context chip shows a small bar with "memory: 92% written · view 64/128 KB", and the phones and the web show the same over the composer.
