# Backplane 0.14.0 Alpha

## Alpha

Backplane is a workspace for agentic hardware development: your agent edits KiCad and FreeCAD files while you follow the work in board, schematic, 3D and mechanical viewers, on the desktop, in a browser or on your phone. 0.14.0 is the first release we call an **Alpha**. It is meant for people who want to build hardware with agents today and are happy to report what breaks. Expect rough edges, frequent updates, and a few platforms (Windows, macOS without notarization) that need extra steps; the known ones are listed below.

## Highlights

**Projects and threads**
- Click a project's name to open its home, built from what the project contains: spec, README, conversations, board, schematic and 3D viewers, fab and mech parts. Typing there starts a conversation (#812).
- Finished threads, including worker threads an agent delegated, settle on their own after a quiet period; history is kept and a new message reopens them (#806, #820).
- Red sidebar rows say what they want from you, a failed turn says why once and offers Retry, and follow-ups say they are unread (#814, #813, #815).
- A restart shows as one quiet grey row, and the empty Commands palette lists threads waiting on you first (#818, #819).
- Add project has a folder picker, and the order bar waits until you have sent your first message (#816, #817).

**Accounts**
- When a provider account runs out, Backplane first switches to another account of the same provider with the most allowance left, then tries other providers (#787, #797).

**Long conversations**
- Conversations that were too large to open now load: views are bounded, recent history streams first, and scrolling back no longer freezes or jumps (#804, #807, #811).

**Phone and pairing**
- Phones can open images from messages, and large files upload from disk (#798, #756).
- A fresh phone or browser opens a "Connect to your Backplane hub" screen: pair with a link, QR code or short code. A revoked phone asks to be re-paired, and Settings → Devices lists and revokes sessions (#773).
- Every client now presents its pairing credential, including browsers on the hub's own machine; the desktop app does this automatically (#824).

**Browser, allowance, and more**
- The in-app Browser reconnects by itself and no longer gets stuck (#802).
- The remaining-allowance bar recovers with per-account quotas instead of showing "unknown" (#694, #802).
- Hub CPU use drops: settling no longer floods notices (#822).
- The hub ignores a repository's own git commands and config (#821).
- Optional anonymous usage counts: a first-run popup explains them, they are on by default, and you can turn them off there or later in Settings (#630, #717).
- Windows (experimental) works natively for project folders, CLI discovery, KiCad extraction and update checks (#707, #712, #688, #736).

## Known limitations

- **macOS builds are not notarized.** Gatekeeper will refuse the first launch. Do this once:
  - Open `Backplane.app` from Finder with right-click (or Control-click) → **Open** → **Open**; or
  - on macOS 15 and later, try to open it once, then go to System Settings → Privacy & Security and click **Open Anyway**; or
  - from a terminal: `xattr -dr com.apple.quarantine /Applications/Backplane.app`
- **Windows is experimental.** Extract the whole zip into a writable folder and run `Backplane.exe`. Shell commands need Cygwin tools; see [installation](../install.md).
- **Notarization will follow** once an Apple Developer ID exists, and the override above will no longer be needed.
