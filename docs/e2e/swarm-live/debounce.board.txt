      - **Why over alternatives**:
        - *Immediate-edge lockout* fails on noise glitches (flips immediately on a single spike).
        - *Shift register (N consecutive samples)* resets completely on one late bounce/EMI bit, stalling or adding worst-case latency.
        - *Saturating integrator* (`c` in `[0, M]`: `+1` on `1`, `-1` on `0`, clamped; output becomes `1` at `c == M`, `0` at `c == 0`, else holds) rejects glitches `< M` samples, settles faster on mostly-settled bouncy edges, and its hysteresis guarantees no double-edges once flipped.
      - **Count `M`**: At `0.5 ms` period and up to `2.0 ms` bounce, `2.0 / 0.5 = 4` intervals = **5 samples** (`M = 5`, or `int(bounce_ms / sample_ms) + 1` so even a 4-sample / 1.5–2.0 ms glitch cannot cross threshold; open to `M = 4` vs `M = 5` thoughts).
      - **Proposed API**: `debounce(samples: Iterable[int], *, initial: int = 0, threshold: int = 5) -> list[int]` (init `c = threshold if initial else 0`, validate `0/1` and `threshold >= 1`, empty input -> `[]`).
