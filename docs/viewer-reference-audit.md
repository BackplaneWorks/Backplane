Decoding the **entire** audio of each with `ffmpeg -vn -af astats=metadata=0:reset=0 -f null -` gives min=max=0, peak and RMS −∞ dB, entropy 0, and no NaNs/Infs: A 1,113,088 samples/channel, B 1,001,472 samples/channel (decoder padding included). **Both tracks are digital silence; there is no narration, music, or audible interaction to transcribe.** `volumedetect`'s −91 dB floor alone was not treated as proof; floating-point `astats` established exact silence.

Evidence codes used throughout:

- **O**: directly observed in recording pixels. A control being visible is weaker evidence than a successful interaction.
- **I**: interpretation or proposed implementation; not established by the recording.
- **S**: independently inspected Backplane source at the pinned commit; not a runtime test.
- **P**: independently checked primary external source. Only the explicitly identified alloy data has this status.
- **U**: unverified, unreadable, or not exercised; do not fill in hidden choices or claim a solver works.

Original reference-app discovery: A identifies itself as `AIF22 / LOCAL PREVIEW`, document `AIF22 MainBoard`, `85 Components · KiCad 10.0.5`; B's panes identify `G3N3`. Neither recording shows an address bar, application version, repository, API endpoint, or source path. Read-only unique-string searches in plausible local YoungUI, k3eda, EESloppa, T3CAD_Example, t3cad-release-work and Backplane folders found no matching source for `AIF22`, `Reflow simulator`, or `Thermal preview`. The integration owner has no further original URL/path. **The reference app's implementation, hidden menus and solver internals were therefore not independently inspected.** No guessed URL was substituted for it.
