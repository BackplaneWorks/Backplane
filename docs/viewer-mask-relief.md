# Estimated mask relief

Realistic raster rendering can add two shading-normal maps derived from actual outer copper clipped by actual soldermask geometry. Coating transfer0.5 and smoothing0.08mm are presentation estimates. Copper thickness is measured from source geometry. This adds no displacement, silhouettes, occlusion, mask holes, manufacturing data or authored CAD geometry. Source RGB, PBR factors, source layer counts and original file stay unchanged. A separate lighting change adds only one lower environment diffuser at(0,0,−1),spread0.12,power0.45; upper environment and analytic key/fill/+Yrim, exposure and all material factors stay unchanged. The exact reflection direction of an orthographic underside is−Z. In the isolated six-frame raster comparison, the actual underside interior averaged about41displaycodes with subtle nonzero relief response. Top/vertical metal reflections also changed. This is raster readability evidence, not photorealism, universal orientation or traced-map qualification.

Eligibility has two independent parts:

- The loader privately records a successful same-origin credentialed asset fetch and actual SHA256 comparison against a supplied64hex digest, with saved key/revision, PCB source and gltf-y-up orientation. Asset JSON has no recipe/kind field. There is no claimed recipe validation or SHA allowlist. A PCB path alone is insufficient.
- Original GLTF mesh/material associations must identify one common `_PCB`, `_copper`, `_soldermask` name stem. Two mask faces must have opposing planar native-Y normals and matching finite extents. Aggregated substrate bounds and distinct horizontal outer-copper planes must be unambiguous and consistently ordered between substrate and mask. Native coordinates, board dimensions, elevations and copper steps are measured. Unknown/no-Cu/compact/STEP/ambiguous/nonrigid cases retain original rendering with `maskReliefReason`.

Authored material extensions, normal/clearcoat/bump/displacement maps and existing textures take precedence conservatively. This first implementation skips a face pair if any such feature is present, including textures that could use existing UV channels. Existing unused UV/tangent attributes may be replaced only in private copies. Maps use native X/Z UV, no texture flip, no color transfer, +X tangent with front−1/back+1 handedness. Both physical coating normal slots use the same map. Actual mask triangles preserve source openings; pads are excluded. Covered vias remain covered where the source mask covers them.

The source scene remains the picking, component-bounds, UUID, hierarchy, material-role and solder-anchor authority. A separate raster scene contains proxies borrowing source geometry/materials, except for two mask proxies owning exact position/normal/index copies plus private UV/tangents/material/map. Original nodes' geometry/material bindings and parser associations never change. Stage light proxies borrow environment and own their cloned shadow resources. No source child is moved or attached to the presentation scene. Compatible opaque raster batching may consume this representation; it is released before its borrowed mask resources.

Work starts on a deferred task only after the renderer's actual original `visible && firstFrame` framebuffer proof. No pending request waits indefinitely for a first-frame event. Source identity, model, revision/digest proof, policy, context/lifecycle epoch and visibility guard all work and atomic commit. Traversal, vertices, triangles, raster scanlines and smoothing are bounded and yield tasks; cancellation observes both caller load-abort and presentation abort. Partial owned resources are rolled back. Policy/revision/model/hide/context-loss/pathtrace/solder-replacement/dispose retires derived batches/guides, then presentation nodes, then owned maps/material/geometry before original-policy/source teardown. Disposal is idempotent and clears retained array references.

Delta B captures a ready, synchronized eligible owned coating scene for a new trace. Source picking and bounds remain original. If coating preparation is pending/unavailable when trace is requested, it is canceled and the original scene is traced with a persistent `tracePresentationReason`; later work never promotes into an active BVH/accumulator. Source/proof/presentation/epoch are captured with BVH ownership. Retirement releases tracer/worker references before owned geometry/maps; handles detach before stop can re-enter during hide/dispose.

The geometric-normal/depth guide and mixed-footprint test stay unchanged. A separate `ShadingNormalGuide` target contains RGBA8 shading normals and its OWN UnsignedInt depth texture. No borrowed attachment or private framebuffer access is used. The actual extra attachment payload is eight bytes per target pixel, bounded to two million pixels and16MiB before allocation (12,600,000bytes at1500×1050). This corrects the earlier color-only6.3MB estimate. CPU bookkeeping/proxy objects and driver overhead are separate. There are two extra scene draws at presentation: full captured-scene depth-only override with color writes disabled, then at most two generated mask proxies with depth testing and no depth writes over alpha0. Every temporary scene/background/clear/render-target override restores in finally. Original mesh material bindings do not change in these extra passes. Alpha1 identifies mapped samples; alpha0 uses geometric normals exactly. The unchanged neighborhood weights use shading normals while depth-plane rejection still uses geometric normals. No filter constants/strides, sampler, HDR resolve, tone map, offsets, source PBR or global texture-slot changes are included.

Only generated mask maps with identical base/coat map and scale qualify. When mapped guides are present, depth contributors must use DoubleSide, allowOverride:true, solid rendering and the default LessEqualDepth comparison. Single-sided/open-face, override-exempt, wireframe and nondefault-depth contributors fall back to raw before any extra target allocation. Original no-map traces retain their prior no-extra-guide path. Cached mapped proxies copy current source material visibility on every render, including visibility changes without a material version bump. Authored/divergent/unknown normals, unsupported depth-pass features, stale state, target overflow or render failure immediately draw the current resolved RAW HDR and retain an explicit `denoiseGuideReason` and `denoised:false`. Final-sample/time-budget paths cannot relabel that image filtered. Explicit present redraws the linked selection overlay after a valid raw fallback while keeping denoised:false; a pending resolve with no new frame does not claim a presentation. Persistent trace/guide fields survive generic per-tile reason updates. Trace ownership retirement clears captured-success state; every new capture recomputes its presentation/reason. Only an explicit fallback tagged with the current source proof, generation and presentation epoch can survive into an original-scene capture, so policy-driven refresh cannot describe a retired coating owner as current. Cache identity includes source material/geometry/map identities and versions/normal scale/channel/side; proxies track current world matrices/visibility. Cache retirement disposes only owned materials/target/depth and clears borrowed references. No extra22k-node scene copy is created.

`guideBytes` conservatively includes existing geometric color+depth and albedo color+implicit depth (16bytes per trace pixel), the extra owned guide attachment payload, filter targets and HDR resolver payload. The previous accounting omitted albedo depth; the diagnostic correction does not add another baseline resource. Neither CPU stand-ins nor a tiny worker build qualify real guide coverage, texture sampling, depth equality, latency or appearance. A separate authorized browser/GPU gate is still required.

Limits retain source96MiB/1Mtriangles and hierarchy60000nodes/depth128/32768meshes. Relief caps220000relevant source triangles, two1024 maps,8388608two-face pixels,80M raster visits,160MiB complete typed work and80MiB retained typed payload. Retained totals include mask/copper coverage, normal bytes, copied geometry and UV/tangents; work includes both faces' scratch and copied geometry, conservatively including overwritten UV/tangent copies. Proxy object/driver/RSS overhead is separate. The existing1024 trace texture slot is unchanged. Generated traces add at most two unique normal layers; layer qualification uses a bounded source-texture inventory and a32MiB/8layer color-array ceiling, with original trace fallback if exceeded. Independent solder12000mesh/300000triangle limits are unchanged.
